The issue you experienced on Mobile Chrome is extremely common. Mobile Chrome on Android handles direct relative links to PDF files () by trying to pass the raw file to an internal viewer or external app. If the device doesn't have Google Drive or an explicit PDF handler configured as default for Chrome, Chrome often fails silently, shows a blank screen, or throws a "Cannot open PDF" / "File format not supported" error. Firefox, on the other hand, includes its own built-in PDF renderer (PDF.js) directly inside the browser. Why It Happens & How to Fix It Missing download Attribute: Without forcing a browser download, Chrome tries to display inline PDFs using whatever app the operating system assigns. Direct File Pathing: Android Chrome struggles with local relative paths (docs/file.pdf) when trying to pass them off to external viewer apps. Solution 1: Force Direct Download (Quickest Fix) Adding the download attribute to your HTML tags forces Chrome to download the PDF file directly to the phone's "Downloads" folder, which then opens seamlessly via Android's default file viewer notification.
